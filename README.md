# Maquette de refonte — Créances (non officielle)

**Ceci n'est pas le site officiel de la commune de Créances.** Le site officiel est https://ville-creances.fr/.

Maquette de proposition réalisée par Localia (Thibaut Marie) le 25 octobre 2026, à partir des contenus publics du site actuel.
Elle n'a été ni demandée ni validée par la mairie.

- Contenus repris du site actuel ; les informations anciennes sont marquées « à vérifier », les manquantes « à compléter par la mairie ».
- Le logo et les photos appartiennent à la commune ou à leurs auteurs : droits de réutilisation non établis. Ils seront retirés sur simple demande.
- Le formulaire de contact n'envoie rien.
- Le site demande aux moteurs de recherche de ne pas l'indexer (`robots.txt`, balise `noindex`).
- Un **assistant questions-réponses** (bulle en bas à droite) répond uniquement à partir des pages du site. Version sans IA sur GitHub Pages ; version IA prête à brancher dans [`chatbot-ia/`](chatbot-ia/README.md).
- Les actualités sont illustrées par des **photos d'illustration Unsplash** (licence Unsplash, usage gratuit), créditées sous chaque article. Elles ne montrent pas Créances.
